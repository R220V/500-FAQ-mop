Перевірка знань по темі "React"

▸1. Що таке React?

React — це бібліотека JavaScript для створення користувацьких інтерфейсів. Основна концепція — компонентний підхід та декларативний рендеринг.

  • Розроблена Facebook
  • Дозволяє створювати повторно використовувані компоненти
  • Використовує Virtual DOM для оптимізації оновлень
  • Підтримує хуки для роботи зі станом і побічними ефектами у функціональних компонентах
function Hello() {
  return <h1>Привіт, React!</h1>;
}

// Використання
ReactDOM.render(<Hello />, document.getElementById('root'));

Порада: розділяйте UI на маленькі компоненти для кращої підтримуваності та тестованості.

▸2. Що таке JSX?

JSX — це синтаксис, що дозволяє писати HTML-подібний код всередині JavaScript. React компілює його у звичайні виклики React.createElement.

  • JSX спрощує читання та написання UI-коду
  • Можна використовувати JavaScript-вирази всередині { }
  • Вимагає один кореневий елемент для кожного блоку
const element = <h1>Привіт, JSX!</h1>;

// З JavaScript виразом
const name = "Анна";
const greeting = <h1>Привіт, {name}!</h1>;
▸3. Що таке компонент у React?

Компонент — це самостійна частина інтерфейсу, яку можна повторно використовувати. В React є два типи компонентів:

  • Функціональні (function components)
  • Класові (class components)
// Функціональний
function Button() {
  return <button>Натисни мене</button>;
}

// Використання
<Button />

Порада: для нових проектів рекомендується використовувати функціональні компоненти з хуками.

▸4. Що таке пропси (props)?

Props — це параметри, які передаються компоненту ззовні, роблячи його гнучким та повторно використовуваним.

  • Не змінюються всередині компонента
  • Дозволяють передавати дані та функції
function Greeting(props) {
  return <h1>Привіт, {props.name}!</h1>;
}

// Використання
<Greeting name="Анна" />
▸5. Що таке state?

State — це внутрішній стан компонента, який може змінюватися, викликаючи перерендер.

  • Використовується для динамічних даних
  • Зміни стану викликають оновлення UI
function Counter() {
  const [count, setCount] = React.useState(0);

  return <button onClick={() => setCount(count + 1)>{count}</button>;
}

Порада: у складних станах розгляньте useReducer замість useState.

▸6. Як створити функціональний компонент?

Функціональний компонент — це звичайна функція, яка повертає JSX.

function Welcome() {
  return <h1>Ласкаво просимо!</h1>;
}

// Використання
<Welcome />

Порада: додавайте хуки для керування станом і побічними ефектами.

▸7. Як створити класовий компонент?

Класовий компонент — ES6 клас, що розширює React.Component і має метод render().

class Welcome extends React.Component {
  render() {
    return <h1>Ласкаво просимо!</h1>;
  }
}

Порада: класові компоненти використовують рідше у сучасних проєктах через наявність хуків.

▸8. Що таке Virtual DOM?

Virtual DOM — це легка копія реального DOM у пам’яті. React порівнює старий та новий Virtual DOM і мінімізує зміни у реальному DOM для продуктивності.

  • Зменшує кількість операцій з DOM
  • Покращує продуктивність великих додатків
▸9. Що таке useState?

useState — хук для додавання стану у функціональний компонент.

const [name, setName] = React.useState("Анна");

// Оновлення стану
setName("Петро");

Порада: передавайте функцію у useState для відкладеної ініціалізації складних значень.

▸10. Що таке useEffect?

useEffect — хук для виконання побічних ефектів у функціональних компонентах.

  • Може замінювати componentDidMount, componentDidUpdate, componentWillUnmount
  • Використовується для fetch-запитів, підписок на події, таймерів
React.useEffect(() => {
  console.log("Компонент змонтовано або оновлено");
  return () => console.log("Компонент буде видалено");
}, []);
▸11. Що таке ключі (keys) у списках?

Key — унікальний ідентифікатор для елементів списку, який допомагає React відстежувати елементи при оновленні.

const items = ["Яблуко","Банан"];
items.map((item, index) => <li key={index}>{item}</li>);

Порада: використовуйте унікальні значення, а не індекси, якщо порядок елементів може змінюватися.

▸12. Що таке компонент вищого порядку (HOC)?

HOC — функція, яка приймає компонент і повертає новий компонент із додатковими можливостями.

function withLogging(WrappedComponent) {
  return function(props) {
    console.log("Рендер компонента");
    return <WrappedComponent {...props} />;
  }
}
▸13. Що таке умовний рендеринг?

Умовний рендеринг дозволяє показувати різний UI залежно від стану або пропсів.

function Greeting({ isLoggedIn }) {
  return <div>{isLoggedIn ? "Привіт, користувач!" : "Будь ласка, увійдіть"}</div>;
}
▸14. Як обробляти події в React?

Події в React пишуться як camelCase і передаються функції, а не рядком.

function Button() {
  function handleClick() {
    alert("Натиснули кнопку!");
  }
  return <button onClick={handleClick}>Натисни</button>;
}
▸15. Як передавати функції через props?

Функції можна передавати у пропсах для взаємодії між компонентами.

function Child({ onClick }) {
  return <button onClick={onClick}>Натисни</button>;
}

function Parent() {
  function sayHello() { alert("Привіт!"); }
  return <Child onClick={sayHello} />;
}
▸16. Що таке controlled component?

Controlled component — це форма, у якій значення керується станом React.

function Form() {
  const [value, setValue] = React.useState("");
  return <input value={value} onChange={e => setValue(e.target.value)} />;
}
▸17. Що таке uncontrolled component?

Uncontrolled component — форма, значення якої контролюється самим DOM.

function Form() {
  const inputRef = React.useRef();
  function handleSubmit() {
    alert(inputRef.current.value);
  }
  return <>
    <input ref={inputRef} />
    <button onClick={handleSubmit}>Відправити</button>
  </>;
}
▸18. Що таке фрагменти (Fragments)?

Fragment дозволяє групувати елементи без додаткового DOM-вузла.

function List() {
  return <React.Fragment>
    <li>Елемент 1</li>
    <li>Елемент 2</li>
  </React.Fragment>;
}
▸19. Як використовувати refs?

Refs дозволяють отримати доступ до DOM-елементів або компонентів.

function InputFocus() {
  const inputRef = React.useRef();
  return <>
    <input ref={inputRef} />
    <button onClick={() => inputRef.current.focus()}>Фокус</button>
  </>;
}
▸20. Що таке lifting state up?

Lifting state up — переміщення стану у спільний батьківський компонент для синхронізації між дітьми.

function Parent() {
  const [value, setValue] = React.useState("");
  return <>
    <Child1 value={value} setValue={setValue} />
    <Child2 value={value} />
  </>;
}
▸21. Що таке умовний рендеринг?

Умовний рендеринг дозволяє показувати різні елементи залежно від логіки.

{isLoggedIn ? <LogoutButton /> : <LoginButton />}
▸22. Як рендерити списки в React?

За допомогою методу map(), створюючи компонент для кожного елемента.

const fruits = ["Яблуко","Банан"];
fruits.map((fruit, index) => <li key={index}>{fruit}</li>);
▸23. Що таке ключі (keys) у списках?

Key — унікальний ідентифікатор для кожного елемента списку, щоб React ефективно оновлював DOM.

▸24. Що таке controlled component?

Форма, значення якої контролюється станом React через value і onChange.

const [value, setValue] = React.useState("");
<input value={value} onChange={e => setValue(e.target.value)} />
▸25. Що таке uncontrolled component?

Форма, значення якої контролює DOM сам по собі, без стану React.

const inputRef = React.useRef();
<input ref={inputRef} />;
▸26. Як обробляти події в React?

Події передаються через camelCase атрибути і функції-обробники.

<button onClick={() => alert("Натиснуто!")}>Клік</button>
▸27. Що таке PropTypes?

Бібліотека для валідації типів пропсів компонентів.

import PropTypes from 'prop-types';
MyComponent.propTypes = {
  name: PropTypes.string.isRequired,
  age: PropTypes.number
};
▸28. Що таке defaultProps?

Значення пропсів за замовчуванням, якщо вони не передані компоненту.

MyComponent.defaultProps = {
  name: "Гість"
};
▸29. Що таке form validation у React?

Механізм перевірки даних форми перед їхнім відправленням.

const handleSubmit = e => {
  e.preventDefault();
  if(!email) alert("Введіть email");
};
▸30. Що таке controlled checkbox / radio?

Контролювані поля вибору через стан React.

const [checked, setChecked] = React.useState(false);
<input type="checkbox" checked={checked} onChange={e => setChecked(e.target.checked)} />
▸31. Що таке lifting state up?

Підйом стану вгору – передача стану від дочірніх компонентів до спільного батька для синхронізації.

const [value, setValue] = React.useState("");
<Child value={value} onChange={setValue} />
▸32. Що таке React Fragment?

Компонент, що дозволяє групувати елементи без додаткового DOM-елемента.

<React.Fragment><Child1 /><Child2 /></React.Fragment>

Або короткий запис: <></>

▸33. Що таке useRef?

Хук для збереження посилань на DOM-елементи або збереження змінних між рендерами.

const inputRef = React.useRef();
<input ref={inputRef} />;
▸34. Що таке useMemo?

Хук, який кешує результат функції для оптимізації продуктивності.

const computed = React.useMemo(() => heavyComputation(value), [value]);
▸35. Що таке useCallback?

Хук для запам’ятовування функцій, щоб не створювати їх заново при кожному рендері.

const handleClick = React.useCallback(() => console.log(value), [value]);
▸36. Що таке higher-order component (HOC)?

Функція, яка приймає компонент і повертає новий компонент з додатковим функціоналом.

const withLogger = Wrapped => props => {
  console.log(props);
  return <Wrapped {...props} />;
};
▸37. Що таке render props?

Техніка, коли компонент приймає функцію як пропс і викликає її для рендерингу.

<DataProvider render={data => <Child data={data} />} />
▸38. Що таке context API?

Механізм для передачі даних між компонентами без пропсів на кожному рівні.

const ThemeContext = React.createContext("light");
<ThemeContext.Provider value="dark"><App /></ThemeContext.Provider>
▸39. Як споживати context?

За допомогою хука useContext або компонента Context.Consumer.

const theme = React.useContext(ThemeContext);
▸40. Що таке React.lazy?

Функція для динамічного імпорту компонентів, що дозволяє code splitting.

const LazyComponent = React.lazy(() => import('./MyComponent'));
<React.Suspense fallback=<div>Loading...</div>>
  <LazyComponent />
</React.Suspense>
▸41. Що таке Suspense?

Компонент, який дозволяє відображати fallback, поки дочірні компоненти завантажуються асинхронно.

<React.Suspense fallback=<div>Loading...</div>>
  <LazyComponent />
</React.Suspense>
▸42. Що таке error boundaries?

Компоненти, що ловлять помилки в дочірніх компонентах і відображають запасний UI.

class ErrorBoundary extends React.Component {
  state = { hasError: false };
  static getDerivedStateFromError() { return { hasError: true }; }
  render() { return this.state.hasError ? <h1>Error!<h1> : this.props.children; }
}
▸43. Що таке controlled component?

Форма або елемент, значення якого керується станом React.

const [value, setValue] = React.useState("");
<input value={value} onChange={e => setValue(e.target.value)} />
▸44. Що таке uncontrolled component?

Елемент форми, який сам керує своїм станом, наприклад через ref.

const inputRef = React.useRef();
<input ref={inputRef} />
▸45. Що таке reconciliation?

Процес порівняння нового та старого Virtual DOM і оновлення реального DOM мінімальним способом.

▸46. Що таке key у списках React?

Унікальний ідентифікатор елемента для ефективного оновлення списку.

{items.map(item => <li key={item.id}>{item.name}</li>)}
▸47. Що таке PureComponent?

Класовий компонент, який реалізує shouldComponentUpdate з поверхневим порівнянням props і state.

▸48. Що таке memo?

Функція для обгортання компонента і запобігання його перерендеру, якщо props не змінилися.

const MemoComponent = React.memo(Component);
▸49. Що таке useReducer?

Хук для управління складним станом через редюсер (схожий на Redux).

const [state, dispatch] = React.useReducer(reducer, initialState);
▸50. Що таке synthetic event?

Об’єкт події React, що нормалізує браузерні події для кросбраузерності.

▸51. Що таке prop drilling?

Передача пропсів через багато рівнів компонентів, навіть якщо проміжні не використовують їх.

▸52. Як уникнути prop drilling?

За допомогою Context API або state management (Redux, Zustand).

▸53. Що таке lazy loading компонентів?

Динамічне завантаження компонентів лише тоді, коли вони потрібні.

▸54. Що таке code splitting?

Розділення JS-коду на менші частини для прискорення завантаження сторінки.

▸55. Що таке hydration?

Процес, коли React «підключається» до вже відрендереного HTML на сервері.

▸56. Що таке server-side rendering (SSR)?

Рендеринг React-компонентів на сервері замість браузера.

▸57. Що таке client-side rendering (CSR)?

Рендеринг React-компонентів безпосередньо в браузері.

▸58. Що таке static site generation (SSG)?

Попереднє рендерення сторінок під час збірки для швидкого завантаження.

▸59. Що таке hydration mismatch?

Помилка, що виникає, коли серверний HTML не відповідає HTML після клієнтського рендеру.

▸60. Що таке React Profiler?

Інструмент для вимірювання продуктивності React-компонентів.

<Profiler id="App" onRender={(id, phase, actualTime) => { console.log(actualTime); }}>
  <App />
</Profiler>
▸61. Що таке SuspenseList?

SuspenseList дозволяє координувати порядок відображення кількох Suspense-компонентів, щоб контролювати їхнє завантаження.

<SuspenseList revealOrder="forwards">
  <Suspense fallback=<div>Завантаження 1...</div>><Component1 /></Suspense>
  <Suspense fallback=<div>Завантаження 2...</div>><Component2 /></Suspense>
</SuspenseList>
▸62. Що таке useLayoutEffect?

Хук, який виконується синхронно після того, як всі зміни DOM застосовані, але перед тим, як браузер оновить екран.

React.useLayoutEffect(() => {
  // логіка, що потребує вимірювання DOM
}, [dependencies]);
▸63. Різниця між useEffect і useLayoutEffect?

useEffect виконується асинхронно після рендеру, не блокує оновлення екрану. useLayoutEffect виконується синхронно після змін DOM, перед тим як браузер промалює UI.

▸64. Що таке useReducer?

useReducer — хук для керування складним станом за допомогою редюсера.

const [state, dispatch] = React.useReducer(reducer, initialState);

// приклад reducer
function reducer(state, action) {
  switch(action.type) {
    case 'increment': return { count: state.count + 1 };
    case 'decrement': return { count: state.count - 1 };
    default: return state;
  }
}
▸65. Переваги useReducer над useState?
  • Краще для складної логіки стану
  • Прогнозовані оновлення через dispatch
  • Легше тестувати reducer-функції
▸66. Що таке controlled component?

Компонент форми, стан якого керується React через value і onChange.

const [value, setValue] = React.useState('');
<input value={value} onChange={e => setValue(e.target.value)} />
▸67. Що таке uncontrolled component?

Компонент форми, який керується самим DOM без контролю React.

const inputRef = React.useRef();
<input defaultValue="текст" ref={inputRef} />
▸68. Що таке PropTypes?

Бібліотека для валідації типів пропсів компонентів.

import PropTypes from 'prop-types';
MyComponent.propTypes = {
  name: PropTypes.string,
  age: PropTypes.number
};
▸69. Що таке defaultProps?

Значення пропсів за замовчуванням, якщо вони не передані.

MyComponent.defaultProps = {
  name: 'Гість'
};
▸70. Що таке key у списках?

Унікальний ідентифікатор елемента списку для оптимізації рендеру.

{items.map(item => <li key={item.id}>{item.name}</li>)}
▸71. Що таке shallow comparison?

Порівняння об’єктів або масивів лише по першому рівню властивостей, без глибокої перевірки.

▸72. Що таке reconciliation priority?

Пріоритет оновлень у React для оптимізації часу рендеру та відгуку UI.

▸73. Що таке React Profiler?

Інструмент для вимірювання продуктивності компонентів.

<Profiler id="App" onRender={callback}></Profiler>
▸74. Що таке hydration?

Процес додавання обробників подій до серверного HTML під час SSR.

▸75. Що таке SSR (Server-Side Rendering)?

Рендер компонентів на сервері, щоб користувач отримав готовий HTML для швидкого завантаження.

▸76. Що таке CSR (Client-Side Rendering)?

Рендер компонентів на клієнті за допомогою JavaScript після завантаження сторінки.

▸77. Що таке React Router?

Бібліотека для навігації між сторінками в SPA-додатках.

▸78. Що таке useParams?

Хук React Router для отримання параметрів маршруту.

const { id } = useParams();
▸79. Що таке useNavigate?

Хук React Router для програмної навігації між маршрутами.

const navigate = useNavigate();
navigate('/home');
▸80. Що таке useLocation?

Хук React Router для отримання поточного об'єкта локації (pathname, search, state).

const location = useLocation();
console.log(location.pathname);
▸81. Що таке lazy loading у React?

Механізм відкладеного імпорту компонентів для зменшення початкового розміру бандлу.

const MyComponent = React.lazy(() => import('./MyComponent'));
<Suspense fallback=<div>Завантаження...</div>>
  <MyComponent />
</Suspense>
▸82. Що таке memo?

HOC для запобігання повторного рендеру компонентів, якщо пропси не змінилися.

const MemoComponent = React.memo(MyComponent);
▸83. Що таке useCallback?

Хук для мемоізації функцій, щоб вони не створювалися заново при кожному рендері.

const memoizedCallback = React.useCallback(() => {
  doSomething(a, b);
}, [a, b]);
▸84. Що таке useMemo?

Хук для мемоізації обчислених значень, щоб уникнути повторних дорогих обчислень.

const memoizedValue = React.useMemo(() => computeExpensiveValue(a, b), [a, b]);
▸85. Що таке forwardRef?

Механізм для передачі ref до дочірнього компонента.

const Input = React.forwardRef((props, ref) => <input ref={ref} {...props} />);
▸86. Що таке useImperativeHandle?

Хук для контролю того, які значення або методи будуть доступні через ref.

useImperativeHandle(ref, () => ({
  focus: () => { inputRef.current.focus(); }
}));
▸87. Що таке Context API?

Механізм для передачі даних між компонентами без пропс-дриллінгу.

const ThemeContext = React.createContext('light');
▸88. Як використовувати Provider і Consumer?

Provider передає значення вниз по дереву, Consumer отримує його.

<ThemeContext.Provider value="dark">
  <Child />
</ThemeContext.Provider>

const theme = React.useContext(ThemeContext);
▸89. Що таке render props?

Техніка, коли компонент приймає функцію як пропс для динамічного рендеру.

<DataProvider render={data => <Child data={data} />} />
▸90. Що таке compound components?

Компоненти, які працюють разом і обмінюються станом через контекст.

▸91. Що таке React Portals?

Механізм для рендеру дочірнього компонента в DOM-елемент, який знаходиться поза батьківським деревом.

ReactDOM.createPortal(<Child />, document.getElementById('modal-root'));
▸92. Що таке hydrateRoot?

Метод для гидратації SSR-документів у React 18+.

import { hydrateRoot } from 'react-dom/client';
hydrateRoot(document.getElementById('root'), <App />);
▸93. Що таке batching?

Групування кількох оновлень стану в одне рендер-цикл, щоб оптимізувати продуктивність.

▸94. Що таке double rendering у StrictMode?

У режимі StrictMode React навмисно виконує подвійний рендер компонентів для виявлення побічних ефектів.

▸95. Що таке Concurrent Mode?

Режим React для паралельного рендерингу, який робить UI більш відзивчивим.

▸96. Що таке transition?

API для позначення станів низького пріоритету, які можна відкладати.

const [isPending, startTransition] = React.useTransition();
startTransition(() => setState(newValue));
▸97. Що таке Suspense для даних?

Механізм для відкладеного рендерингу компонентів, які очікують асинхронні дані.

▸98. Що таке ErrorBoundary у функціональних компонентах?

На сьогодні ErrorBoundary можна робити лише через класові компоненти; у функціональних можна використати сторонні бібліотеки або хук useErrorBoundary.

▸99. Що таке StrictMode?

Компонент для підсвічування потенційних проблем у додатку без впливу на продуктивність в продакшн.

▸100. Як оптимізувати продуктивність у React?
  • Мемоізація компонентів і функцій (React.memo, useMemo, useCallback)
  • Lazy loading компонентів
  • Ключі у списках для уникнення перерендеру
  • Оптимізація рендеру через batching і Concurrent Mode
